# Task 2 - Calculator

## Description

This project is a Python-based Calculator developed as part of the CodSoft Python Programming Internship.

The calculator performs basic arithmetic operations based on the input provided by the user.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles invalid input
- Handles division by zero

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed.
2. Open the terminal.
3. Run the following command:

```bash
python calculator.py
