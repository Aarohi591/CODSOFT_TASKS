# Task 1 - To-Do List

## Description

This project is a simple Python-based To-Do List application developed as part of the CodSoft Python Programming Internship.

The program allows users to manage their daily tasks by adding, viewing, completing, and deleting tasks.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple and easy-to-use interface

## Technologies Used

- Python
