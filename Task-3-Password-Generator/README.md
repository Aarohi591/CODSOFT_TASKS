# Task 3 - Password Generator

## Description

This project is a Python-based Password Generator developed as part of the CodSoft Python Programming Internship.

The program generates a random password based on the length entered by the user.

## Features

- Takes password length from the user
- Generates random passwords
- Uses uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Handles invalid input

## Technologies Used

- Python
- `random` module
- `string` module

## How to Run

1. Make sure Python is installed.
2. Open the terminal.
3. Run the following command:

bash
python password_generator.py
